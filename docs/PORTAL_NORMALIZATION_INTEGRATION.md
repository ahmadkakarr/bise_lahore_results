Uploaded/external-duplicate/uncertain/active/rejected rows are excluded from ready export. 6. Registration-state changes invalidate readiness reports, while cached normalization transforms remain reusable. Final submit-time unique keys remain authoritative against races after file generation. Normalization never uploads or changes portal state.

No live applicant submissions are part of this task. Existing registration receipts remain intact. Handoff files/configuration must pin the exact filtered CSV/provenance/manifest and retain the shared registration DB/campaign; old source confirmations must not be silently extended to newly collected identities.
